# PR 화면 증거

작업별 폴더에 실제 실행한 앱의 PNG/JPEG 캡처만 넣습니다.

```text
docs/pr-evidence/
  photo-review/
    before.png
    after.png
    small-screen.png
```

샘플 파일명은 사용 예시이며 실제 캡처가 들어 있다는 뜻은 아닙니다. 이번 정책 이관은 앱 화면을 바꾸지 않으므로 캡처를 만들지 않았습니다.

화면 내용, 기기/OS, 실행한 코드 커밋, 차이는 PR 본문에 적습니다. 이미지를 커밋한 뒤 `scripts/pr-report.mjs`를 실행하면 고정 커밋 URL로 전후 비교가 만들어집니다. 자세한 절차는 [협업 규칙](../../CONTRIBUTING.md)을 참고합니다.
