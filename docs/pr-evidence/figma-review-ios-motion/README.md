## 전환

기존 색상과 레이아웃을 유지하고 버튼 누름, 검색창 전환, 사진 상세 확대, 사진 응답 전환을 다듬었다. 응답은 고정 시간 대기 대신 전환 완료 시점에 다음 사진으로 진행한다. 시스템의 동작 줄이기 설정을 따르며 회전과 확대 이동을 줄인다.

## 기능의 현재 범위

- 닉네임 수정과 로그아웃은 기존 기능을 연결했다.
- 알림 설정은 계정별로 이 기기에 저장된다. 기존 메시지와 요청 알림 경로에 적용된다.
- 사진 업로드, 댓글, 공감 알림은 설정값 저장까지만 지원한다. 해당 이벤트의 서버 푸시는 아직 없다.
- 프로필 사진 변경과 회원탈퇴는 준비 중 안내를 표시한다. 실제 계정이나 사진을 변경하지 않는다.
- 읽음 기록은 기존 구조대로 기기에 저장된다. 여러 기기의 읽음 동기화는 이번 범위가 아니다.
- 시뮬레이터 조작 검증은 샘플 사진과 대화를 사용한다. 실제 계정 인증, 서버의 읽지 않은 글 집계, 푸시, QR 카메라 인식은 별도 실기기 확인이 필요하다.

## 검증 자료 원칙

전후 화면은 동일한 main 기준판에서 분기한 별도 검증 빌드로 촬영한다. 검증용 로그인, 샘플 데이터와 자동 캡처 코드는 main 대상 PR에 넣지 않는다. 기존 Figma 화면과 댓글 위치는 보존하고 새 캡처를 별도 영역에 추가한다.

## 재현과 검증 범위

- 기준판: `ci/figma-review-baseline`의 `37b04d2`, [실행 기록](https://github.com/kokkumong/Shallpick/actions/runs/44256989754).
- 수정판의 제품 코드: `feat/figma-review-ios-motion`의 `56516e5`.
- 검증용 합본: `ci/figma-review-result`. 동일 제품 커밋에 샘플 데이터와 UI 자동 조작만 추가했다.
- Xcode 26.3, iOS 26.2, iPhone 17 Pro 시뮬레이터. 캡처 원본은 1206×2622이며 Figma에서는 402×874로 표시한다.
- 실제로 검증한 항목과 34개 캡처의 출처는 [validation.json](validation.json)에 기록했다. 실패한 자동 조작을 성공으로 간주하지 않는다.
- 서버 인증과 실제 사진을 사용하는 다중 사용자 검증은 이 기록에 포함하지 않는다.

## 확인 결과

- 일반 앱과 시연 앱 빌드가 통과했다.
- [핵심 흐름 검증](https://github.com/kokkumong/Shallpick/actions/runs/44265379844): 설정 유지, 안 읽은 글 1→0, 핀치 2~6열, 사진 상세, 댓글과 응답 유지, 질문 알림, 새 폴더와 빈 화면을 확인했다.
- [후속 검증](https://github.com/kokkumong/Shallpick/actions/runs/44268512899): 사진 선택과 질문 작성, 수달 추천, 사진별 응답 결과와 댓글, 응답 완료를 확인했다.
- 현재 제품 코드의 앱 테스트 세 개는 두 실행에 걸쳐 통과했다. 겹친 닫기 버튼을 찾던 자동 조작을 수정해 추가 화면 흐름을 끝까지 확인했다.
- 동작 줄이기는 [이전 실행](https://github.com/kokkumong/Shallpick/actions/runs/44262956002)의 제품 코드 `4a6e6b8`에서 시스템 설정을 켜고 상세 보기와 응답까지 통과했다. 이후 전환 코드는 바뀌지 않았고, 사진 셀의 길게 누르기와 탭 분리만 추가됐다. 최신 커밋의 재검증은 앱을 열기 전 iOS 설정 스위치를 켜는 자동 조작에서 실패했다. 최신판의 이 항목을 통과로 기록하지 않는다.
- 기기 사진 화면은 접근 권한 요청 상태를 캡처했다. 실제 사진 접근 허용과 업로드 완료를 검증한 자료는 아니다.
- 사진을 길게 누를 때 선택과 상세 보기가 함께 열리던 문제를 수정했고, 선택과 일반 탭을 각각 확인했다.
- 실행 기록의 `review-captures-*`에는 원본 캡처와 로그가, `iOS-demo-verification-*`에는 실행 영상이 있다. `Shallpick-Appetize-*`는 시뮬레이터용 시연 빌드다. Appetize 계정의 앱은 이 작업에서 교체하지 않았다.
