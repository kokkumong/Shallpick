## 브라우저 시연

SwiftUI 앱을 Windows에서도 직접 눌러볼 수 있도록 Appetize용 iOS 시뮬레이터 빌드를 제공합니다.

- [시연 순서와 빌드 다운로드 안내](docs/browser-demo.md)
- [iOS browser demo 빌드](https://github.com/kokkumong/Shallpick/actions/workflows/ios-demo.yml)
- [시연 사진 출처](docs/demo-assets.md)

시연 모드는 샘플 데이터로 작동하며, 실제 로그인·다중 기기 동기화와 구분합니다.
